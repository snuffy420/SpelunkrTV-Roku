# Changelog

## 1.6 - November 10, 2026

- Add the channel directory, opened with **Options (\*)** or the new DIRECTORY button in the guide footer. Cards show each channel's dial, logo, description, tape and hour counts, and a live NOW PLAYING line. **TUNE IN** plays the channel full screen; **VIEW CHANNEL** selects it in the guide.
- Add channel up/down in full screen. Up goes to the next higher channel, wrapping at either end; the stream opens once flipping settles.
- Add Orange Soda (34) and Waku Waku (300) with their logos.
- Widen the dial and name columns so three-digit dials and the longest channel names show in full. The listings grid now runs flush with the panel's right edge.
- Show the date next to the clock and center the CHANNEL heading.
- Remove the channel description from the guide's info panel; it now lives in the directory.
- Show "Tuning in..." on the playback banner while a new channel's listings load.
- Add `tools/release.py` for the source 7z, and SHA-256 checksums for both downloads.
